About

I'm a software engineer with nearly 14 years of experience building software, including almost six years focused on Python and backend development.

I enjoy working on complex engineering problems: understanding how systems behave, tracing issues across service boundaries, improving data flows, and designing solutions that remain maintainable as products evolve.

At Plytix I work in an e-commerce and product-data environment where backend architecture, external integrations, asynchronous processing and data consistency are central to the engineering challenges. My experience spans backend services, external integrations, APIs, databases, asynchronous processing, and enterprise software. I value clear technical reasoning, pragmatic architecture, and solving the underlying problem rather than adding unnecessary complexity.

I have worked remotely since July 2016. It is a cornerstone of how I balance work and family life, and it has made me a deliberate written communicator and a self-directed engineer.

I like staying hands-on with code while contributing to technical decisions and helping teams deliver reliable software. I'm particularly interested in backend architecture, platform engineering, developer tooling, system reliability, and engineering environments that value autonomy and thoughtful written communication.
